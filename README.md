This project presents an interactive Power BI dashboard that analyzes sales performance and shipment data across countries, products, and time. The goal is to uncover key business insights and support data-driven decision-making.
Analyze shipment distribution across different countries
Identify top-performing products
Understand monthly sales trends
Evaluate positive and negative contributions to revenue
The dashboard reveals strong performance in certain regions and products, but also highlights areas for improvement. Businesses can focus on high-performing products and optimize underperforming ones to increase profitability.
